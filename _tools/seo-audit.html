Settings

Pages and files are fetched through Jina Reader. Nothing is stored on this site. Public pages only.

    What it checks

    Crawling and indexing

    HTTP status and redirects, HTTPS, http→https and www consolidation, robots.txt rules for Googlebot and Bingbot (RFC 9309 matching), noindex, nofollow, nosnippet and canonicals, including ones JavaScript changes.

    robots.txt and sitemaps

    robots.txt presence, server errors, syntax, the 500 KiB limit and Sitemap lines. Sitemaps and sitemap indexes are parsed for XML validity, namespace, the 50,000-URL limit, host consistency, lastmod dates and whether this page is listed.

    On-page content

    Title and meta description quality and length, H1 and heading order, title–H1 alignment, content depth, how much content depends on JavaScript, image alt text and dimensions, and internal links and anchor text.

    Technical and mobile

    Viewport and zoom, language, charset, hreflang codes and self-references, mixed content, favicon, URL hygiene and HTML size.

    Structured data and social

    JSON-LD validity, types and the key properties for rich results (Article, Product, Organization, BreadcrumbList, Event and more), plus Open Graph and Twitter cards.

    Core Web Vitals

    Real-user LCP, INP and CLS from the Chrome UX Report and Lighthouse performance and SEO scores, through the PageSpeed Insights API with your free key.
